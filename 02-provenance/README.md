# 🔍 Zone 2: Provenance, Planning & Anti-Gaslighting

Welcome to the **Provenance** zone. This directory manages end-to-end evidence traceability, work breakdown delivery planning, and automated protection against misinformation and requirement drift.

---

## 🎯 Purpose & Core Responsibilities

1. **Exhaustive Traceability**: Every engineering deliverable generated by Second Brain must be mathematically traceable back to its origin file and line number via `[SRC:...]` citation tags.
2. **Deterministic Delivery Backlog**: Prevents AI token exhaustion and cherry-picking by maintaining an explicit manifest of all database models and product journeys.
3. **Hard Block Enforcement**: Prevents conversational gaslighting and unverified meeting notes from silently overriding production code or signed contracts.

---

## 📄 Key Artifacts

### 1. `delivery-plan.md` (Delivery Plan Manifest)
- Tracks completion of database schema models and product journey deliverables.
- Structured into discrete task items:
  - `## 1. 🗄️ Database Schemas Ingestion`: Grouped by domain (e.g. `Task DB-01: Core Orders`).
  - `## 2. 🚀 Product Journey Deliverables`: Grouped by feature (e.g. `Task DEL-01: Subscription Checkout Flow`).
- Status is updated incrementally by `/brain-deliver` (`[ ]` -> `[x]`).

### 2. `traceability-matrix.md` (Traceability Matrix)
- Comprehensive cross-reference table mapping each deliverable element to its authoritative source:
  | Artifact Element | Provenance Tag | Authoritative Source File & Line | Truth Tier | Verification Status |
  | :--- | :--- | :--- | :--- | :--- |
  | `POST /v1/orders` | `[SRC:BRD#REQ-01]` | `00-raw-inputs/brd/checkout.md#L45` | Tier 2 | VERIFIED |

### 3. `contradictions.md` (Contradiction & Anti-Gaslighting Log)
- Records any detected conflict between incoming claims (e.g. MoM notes or chat prompts) and Ground Truth (code or DDL).
- If any entry has status `OPEN` or `ACTIVE`, an automated **Hard Block** halts deliverable generation until human arbitration records an Architectural Decision Record in `05-adrs/`.

---

## ⚡ Auditing & Execution Commands

- `/brain-audit`: Runs `bin/audit.js` (`npm run audit`) to verify:
  - 100% of PlantUML arrows and API contract fields possess valid `[SRC:...]` tags.
  - 100% of DDL tables are cataloged in `01-ground-truth/entity-catalog.md`.
  - Zero unresolved contradictions exist in `contradictions.md`.
- `/brain-deliver next`: Picks the first pending task in `delivery-plan.md` and generates complete deliverables.
